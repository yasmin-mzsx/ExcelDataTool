# 凭证附件批量处理工具

基于 PySide6 的 Windows 桌面工具，用于批量读取源目录中的 Excel 单据，按单据类型提取并统计指定字段，再填入模板的对应工作表，最终为每个源文件生成一个统计后的 Excel 文件。

当前版本：**V1.0.0**

---

## 功能特性

- **批量处理**：一次选择源目录，处理其中任意数量的 `.xlsx` 文件。
- **按单据自动匹配**：从文件名提取单据名，自动套用对应的统计字段配置。
- **分组汇总**：按单据类型对关键列分组求和，自动剔除“小计 / 合计”行并追加“合计”行。
- **模板化输出**：按单据名定位模板中的工作表，只保留该表并填入统计数据。
- **字段配置界面**：
  - 文件下拉框支持关键字搜索；
  - 统计字段用 `|` 分隔，可保存、恢复默认；
  - 表格展示全部文件配置，支持全选、批量删除、定位未匹配文件；
  - 点击表格行可切换到对应文件。
- **完整性校验**：源目录、模板、输出目录、字段配置任一不满足时，“开始处理”按钮保持禁用并显示原因。
- **后台线程处理**：Excel 处理在 `QThread` 中执行，界面不卡顿；实时回传日志、进度、成功/失败数量。
- **配置持久化**：源目录、模板、输出目录和字段映射自动保存到 `config/app_config.json`，绿色便携。
- **可打包**：支持 PyInstaller 打包为单文件 exe，配置外置于 exe 同级目录。

## 环境要求

- Windows 10 / 11，64 位；
- Python 3.11 及以上，64 位（当前验证环境为 Python 3.14.7）；
- 依赖：PySide6、pandas、openpyxl；打包另需 PyInstaller。

版本对应关系以 `requirements.txt` 中的已验证版本为准。

## 安装与运行

```powershell
# 1. 进入项目目录
cd "C:\Users\Administrator\Desktop\ExcelDataTool_UI_V1.0"

# 2. 安装依赖（建议先创建并激活虚拟环境）

python main.py
```

## 使用流程

1. **选择源文件目录**：选择包含 `.xlsx` 文件的文件夹，程序会列出其中所有非临时文件（自动忽略 `~$` 开头的 Excel 临时文件）。
2. **选择输出模板**：选择一个 `.xlsx` 模板文件。模板中必须包含与单据名同名的工作表（如 `销售出库单`）。
3. **配置字段**：
   - 在“选择文件”下拉框中搜索并选中一个源文件；
   - 在“统计字段”中输入该单据需要统计的列名，多列用 `|` 分隔，例如 `供应商|物料名称|单位|实退数量`；
   - 点击“保存当前配置”；字段映射按下方的“单据名”保存，同一单据名的多个文件共用一份配置；
   - “恢复默认字段”用于恢复该单据的默认配置；“删除选中配置”可勾选后批量删除。
   - 表格中黄色行表示尚未配置统计字段，可点击“定位未匹配 ▼”逐个查看。
4. **选择输出目录**：目录必须已存在，程序不会自动创建。
5. **勾选待处理文件**：在“全部文件配置”表格中勾选要处理的文件（可全选）。
6. **开始处理**：点击“▶ 开始处理”，右侧会显示实时日志、进度和成功/失败统计。处理完成后可勾选“处理完成后自动打开输出目录”。

### 开始按钮的启用条件

以下条件全部满足时才允许开始处理：

- 源目录已选择且目录存在；
- 源目录中至少有一个 `.xlsx` 文件；
- 模板已选择，文件存在且扩展名为 `.xlsx`；
- 输出目录已选择且存在；
- 至少为一个单据配置了非空统计字段。

> 点击“开始处理”时还会额外检查是否勾选了待处理文件。

## 处理逻辑

### 1. 单据名提取

从文件名中只保留中文字符，并去掉“月”字；若结果为空，则回退为去掉扩展名的文件名。例如：

| 源文件名 | 单据名 |
|---|---|
| `01销售出库单_2-189.xlsx` | `销售出库单` |
| `成本调整单2月172#.xlsx` | `成本调整单` |
| `其他出库单（全部）175.xlsx` | `其他出库单全部` |

单据名同时用作字段映射的键和模板工作表的名称。`ui/main_window.py` 与 `core/process_worker.py` 中的提取规则必须保持一致。

### 2. 读取与统计

程序先按单据类型确定表头行，读取源文件后：

- 删除第一列包含“小计 / 合计”的行；
- 只保留配置的目标字段列；
- 删除全空行；
- 对分组列做向下填充（`ffill`），再分组求和；
- 在末尾追加一行“合计”。

各单据类型的处理规则：

| 单据类型 | 表头行 | 字段数 | 分组列 | 特殊处理 |
|---|---:|---:|---|---|
| `完工入库成本查询` | 第 3 行 | 4 | 前 2 列 | 前 2 列向下填充 |
| `折旧明细表` | 第 4 行 | 11 | 前 2 列 | 前 2 列向下填充，其余数值列空值补 0 |
| `其他出库单`、`其他入库单`、`销售出库单`、`销售退货单`、`成本调整单` | 第 1 行 | 5 | 前 4 列 | 前 4 列向下填充 |
| 其他单据（如 `采购退料单`、`生产领料单`、`盘盈单` 等） | 第 1 行 | 4 | 前 3 列 | 前 3 列向下填充 |

`成本调整单` 汇总后会按 `物料编码 | 物料名称 | 调整金额 | 调整原因 | 仓库` 重新排列列顺序。

> 配置的字段数、顺序需与上述规则及模板列结构匹配，否则可能统计失败或输出错列。

### 3. 写入模板

- 在模板中查找与单据名同名的工作表；找不到时该文件记为失败。
- 输出文件只保留该工作表，其余工作表会被删除。
- 数据从第 3 行开始写入；`折旧明细表` 从第 4 行开始（模板前几行为表头）。
- 数据区域自动加细边框，并设置“缩小字体填充”对齐。
- 输出文件命名为“源文件名去扩展名 + `.xlsx`”，保存到输出目录；同名文件会被覆盖。

### 4. 跳过与失败

- 未配置统计字段的文件会被**跳过**，不计入成功/失败数量，日志末尾单独统计“未配置统计字段”数量。
- 模板中缺少对应工作表、读取异常或写入异常的文件会计入**失败**，并继续处理后续文件。
- 全部结束后弹出结果提示；若勾选了自动打开，则打开输出目录。

## 配置文件

程序按“程序所在目录”定位配置：

- 源码运行：项目根目录下的 `config/`；
- 打包运行：exe 同级目录下的 `config/`。

`config/app_config.json` 主要字段：

| 字段 | 说明 |
|---|---|
| `last_source_dir` | 上次选择的源文件目录 |
| `last_template` | 上次选择的模板路径 |
| `last_output_dir` | 上次选择的输出目录 |
| `field_mapping` | 单据名 → 统计字段（多个字段以竖线分隔）的映射 |

程序还支持可选的 `config/default_mapping.json`（默认 `{}`）：启动时先加载默认映射，再由 `app_config.json` 中的用户配置覆盖。可用于集中维护标准字段、随程序分发。

配置在路径变化、保存/删除字段映射以及关闭窗口时自动写回，无需手动编辑。

## 已知限制与注意事项

- **仅支持 `.xlsx`**：不支持老版 `.xls`（运行环境未安装 `xlrd`）。
- **源文件表头位置固定**：不同单据类型的表头行按上表硬编码，源文件格式变化时需同步调整 `core/process_worker.py`。
- **模板 sheet 名必须与单据名一致**，否则处理失败。
- **输出目录必须预先存在**，程序不会自动创建。
- **输出文件按源文件名命名**，同名结果会被覆盖；每个源文件生成一个输出文件，而不是合并为一个工作簿。
- **合计行会作为数据写入模板**，模板中无需预留合计行。
- 配置中的历史路径是本机记录，复制到其他电脑后需重新选择目录。
- 字段名必须与源 Excel 中的列名完全一致（含全角括号、空格等）。

## 开发说明

- `ui/main_window.py`：只负责界面与交互，所有耗时处理通过 `ExcelProcessWorker` 子线程完成。
- `core/process_worker.py`：遍历勾选文件、调度单文件处理、回传日志/进度/计数；单文件业务逻辑集中在 `handle_single_file()`。
- `core/excel_writer.py`：纯 Excel 写入逻辑，不依赖 Qt。
- 新增单据类型时，通常需要同步修改：
  1. `app_config.json` / `default_mapping.json` 中的字段映射；
  2. `process_worker.py` 中的表头行与分组规则（如属于新的特殊类型）；
  3. 模板中新增同名工作表。
